실시간 스마트공장 KPI 모니터링 대시보드 (시뮬레이션 데이터).


## 기능

- ⭕ OEE (종합설비효율) 게이지 = 가동률 × 성능 × 품질
- 📈 분당 생산량 60분 추이 차트
- ⚙️ 설비 6대 상태 카드 (온도·진동 실시간 시뮬레이션)
- 🔔 알람 피드 (과열 경고 → 자동 정지 → 재가동 이벤트)
- ● LIVE 표시 · 2초마다 갱신

## 기술

- Vanilla JS + Canvas 차트 + SVG 게이지
- 완전 클라이언트 사이드 시뮬레이션
